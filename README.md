• Pillow Covers

• Mattresses

• Towels

====================================================

CORE DESIGN DIRECTION

====================================================

The website must look like it was designed by a senior professional UI/UX designer for a real premium Indian home décor company.

It must NOT look AI-generated.

Visual personality:

Premium

Elegant

Warm

Modern

Indian

Sophisticated

Editorial

Trustworthy

Comfort-focused

Product-focused

The design should feel closer to a premium home décor showroom / lifestyle brand than a generic ecommerce template.

Avoid:

• Generic AI landing page layouts

• Excessive rounded cards

• Excessive gradients

• Glassmorphism

• Neon effects

• Floating blobs

• Random decorative shapes

• Cartoon illustrations

• Excessive shadows

• Excessive blue backgrounds

• Huge unnecessary typography

• Over-animation

• Generic stock-style layouts

• Repetitive cards

• Fake-looking AI interiors

Use photography, typography, spacing and composition to create the premium feel.
